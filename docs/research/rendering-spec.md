# DNS 网络舞台渲染测量

本轮针对参考站 Protocol Explorer 的中文版 DNS 课，在 Chromium 的 `1280×800` 视口测量；其中实际 SVG 是 `632×464` CSS px。以页面现场的 DOM、计算后样式与动画采样为准，再用发布包确认算法。没有执行下载到本地的站点脚本，也没有用原站 SVG、插画或 CSS 作为样稿资源。

- 现场原始证据（本地忽略目录）：`research/_downloads/ref-dns-render-{0…5}.svg`、`ref-dns-render-3-active.svg`、`ref-dns-render-measurements.json`、`ref-dns-motion-{1…5}.json`。0 是未播放的概览；各步骤由目录点击进入，在步骤提示出现后约 800 ms 保存 SVG。另在步骤 3 查询飞行时补抓一帧。动画以 `requestAnimationFrame` 读取，通常每约 67 ms 记一条；时间相对开始采样，包含自动化点击开销，不等于报文表中的捕获时间。
- 静态证据：`research/_downloads/rea-5.json` 的 `semantic_graph` 将符号定位到 `assets/index-CNPseYOQ.js`；线型和关键帧来自同目录的 `index-CwjpA-vk.css`。这里记录的是观测值与算法说明，不转载实现。

## 连线、箭头和云

一个邻接关系是**两条方向相反的短直线**，不是一条双头箭头，也不是贯穿设备的折线。默认与激活线均使用 `6 5` 的虚线；未激活／激活线宽为 `2`／`2.4` SVG 单位，状态过渡 `350 ms`。虚线仅在激活时按 `550 ms` 一周期向终点移动，偏移量每周期减少 `11`。现场两种状态的 `opacity` 与 `stroke-opacity` 均为 `1`，浅淡效果来自闲置色，不是半透明。

## 镜头与动画

SVG 舞台没有外层摄像机 transform；镜头由根 SVG `viewBox` 驱动，居中等比显示。节点本身可有瞬时 transform。步骤中会继续展开场景，下表分清“约 800 ms 抓帧”和更晚的值；不是用一组六个固定视框取代动画。

| 进入状态 | 浏览器抓帧 `viewBox`（x, y, 宽, 高） | 后续行为 |
| --- | --- | --- |
| 0 概览 | `44.77 -19.52 1099.78 807.43` | 全景，12 条灰色路径 |
| 1 请求 | `-36.36 228.10 551.22 404.69` | 约 1.6 s 到客户端近景 `-48.37 264.76 470.00 345.06`，再随解析器展开 |
| 2 根区 | `44.77 45.51 789.23 579.43` | 约 3.7 s 扩到 `44.77 -28.29 990.28 727.04` |
| 3 顶级域 | `44.77 -68.37 1099.45 807.19` | 查询在途时为 `44.77 -68.49 1099.78 807.43`，10 条线可见，其中向互联网及顶级域的两条激活 |
| 4 权威 | `44.77 -19.60 1099.78 807.43` | 稳定为概览视框，权威节点进入 |
| 5 回答 | `44.77 -19.52 1099.78 807.43` | 稳定全景，解析器经云、路由器返回客户端；只有回答方向的三条线激活 |

- **取景**：原站对配置的可见节点与标签求外接矩形，加 `14` 单位留白、设置最小视宽 `470`，并检查视图切换条是否覆盖图形。默认 `1100 ms`，逐个插值 `viewBox` 的四个分量；使用三次缓入缓出。样稿改用自绘节点边界与同一曲线时长，保留“客户端近景 → 查找范围扩大 → 全景”，不写死原站的绝对坐标。不同构图、舞台比例和标签大小对应不同视框。
- **报文**：原站在网络 SVG 的独立图层用 `r=6` 实心圆、`r=13` 的 `0.18` 透明外晕和三枚尾迹圆表示包。每条线匀速行进，静态常量为 `0.21` SVG 单位/ms，换跳停 `140 ms`。第 3 步实测圆点从 `(712,229)` 出发，约 2.94 s 到 `(712,313)`，约 3.47 s 到 `(712,404)`，随后接上云到顶级域的一跳。标签以彩色类别条加浅底字段行显示。样稿按自身坐标将速度设为 `0.145` 单位/ms，保留换跳停顿，并用避让位置与短标题显示真实教学帧的信息。
- **节点**：原站随步骤引入节点，入场约 `650 ms`；经过节点有约 `340 ms` 的轻抬，最终到达画 `700 ms` 递增并淡出的圆环（半径 `14 → 60`、透明度 `0.6 → 0`）。样稿用阶段显隐、标签着色、微抬及按等效比例绘制的圆环。减少动态效果时直接定位、停用流动虚线与尾迹。
